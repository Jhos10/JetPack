# 📂 Proyectos Incluidos

## 🌦️ Clima App
Aplicación móvil para consultar el clima en tiempo real utilizando APIs externas.

### ✨ Características
- Consulta de temperatura actual
- Pronóstico del clima
- Interfaz moderna con Compose
- Manejo de estados y navegación

---

## 💰 Finanzas App
Aplicación enfocada en el control de gastos e ingresos personales.

### ✨ Características
- Registro de movimientos financieros
- Estadísticas básicas
- Persistencia de datos
- Diseño intuitivo

---

## 📝 Lista de Tareas
Aplicación para gestionar tareas diarias de forma sencilla.

### ✨ Características
- Crear tareas
- Marcar tareas completadas
- Eliminar tareas
- Interfaz minimalista

---

## 🍔 App de Recetas
Aplicación para visualizar recetas de cocina organizadas por categorías.

### ✨ Características
- Listado de recetas
- Vista detallada
- Imágenes dinámicas
- Navegación entre pantallas

---

## 📰 News App
Aplicación que consume noticias desde una API externa.

### ✨ Características
- Noticias en tiempo real
- Consumo de API REST
- LazyColumn y tarjetas modernas
- Arquitectura organizada
